# Виправлено прив’язку `/full N`

- Дата: 2026-11-18
- Тип: Fix
- Модуль: telegram/list-navigation

Telegram тепер зберігає snapshot видимого списку новин на 2 години. `/full N` спочатку резолвить item ID із цього snapshot, а не бере N-ту позицію з уже зміненої стрічки після on-demand синхронізації.

Клікабельний текст `/full N` прибрано з карток: Telegram може відправити slash-команду без аргументу. Замість нього картка підказує натиснути стабільну inline-кнопку `Розбір N`.
