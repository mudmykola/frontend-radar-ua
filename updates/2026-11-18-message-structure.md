# Перебудовано структуру Telegram-повідомлень

- Дата: 2026-11-18
- Тип: Improvement
- Модуль: telegram/formatters

Короткі картки тепер показують `Що змінилося`, `Кому` і `Що зробити`. Повний розбір має послідовність `Що змінилося → Чому це важливо → Кому → Що зробити → Перевірено → Приклад/Чеклист`.

Для P2 додано явний статус «лише до відома — дія зараз не потрібна». Прибрано дубльовані та водянисті заголовки `Практичний приклад`, `Що зробити зараз`, `Коли можна пропустити`.
